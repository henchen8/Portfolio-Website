<Text label="TELEOPERATION SYSTEM" heading="A 5/8-scale, 6-DOF replica of the i2rt YAM.">

The GELLO leader arm is a 5/8-scale replica of the 6-DOF i2rt YAM, sensed by 7 Feetech STS3215 serial-bus servos per arm — each with magnetic position sensing built in — and built from custom-designed, 3D-printed linkages rather than off-the-shelf hardware.

The servos communicate over a shared serial bus into a Waveshare serial-bus driver board at the base of each arm, which connects to the host machine over a single USB-C cable.
