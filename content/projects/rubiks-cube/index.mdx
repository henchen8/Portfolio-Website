<Text label="MECHANICAL DESIGN" heading="Built for speed, precision, and modularity.">

Every component is custom-designed and 3D printed to enable independent rotation of each cube face. The fully modular architecture allows for easy maintenance and iterative improvements.

End effectors are optimized for precise control and minimal backlash. The design was refined through multiple prototypes to achieve optimal balance between speed, reliability, and robustness.

<Text label="LIVE DEMONSTRATION" heading="Watch a complete solve in under one second.">

The robot processes cube state via computer vision, computes an optimal solution path, and executes the moves with precise stepper motor control. Each solve averages fewer than 20 moves using the Kociemba algorithm.

From the moment the first face turns until the final move completes, the entire sequence runs in under a second.

<Section>
<Text label="ELECTRICAL SYSTEM" heading="Reliable motor control and sensor integration.">

The electrical system bridges computer vision with mechanical actuation. An Arduino MEGA 2560 coordinates six TMC 2209 stepper motor drivers for smooth, precise rotation of each cube face.

- Arduino MEGA 2560 microcontroller
- 6× TMC 2209 V2.0 stepper drivers
- 6× NEMA 17 stepper motors
- Pull-up resistors and decoupling capacitors

<Text label="FIRMWARE" heading="Real-time control with interrupt-driven architecture.">

The C++ firmware manages stepper motor timing, serial communication with the vision system, and move execution. Interrupt-driven design ensures responsive sensor feedback during high-speed operations.

- Precise timing for stepper motor control
- Communication protocols for vision interface
- Configurable motor RPM settings
- Comprehensive error handling

</Text>

<Section>
<Text label="SOLVING ALGORITHM & INTERFACE" heading="Kociemba algorithm with real-time visualization.">

Computer vision detects cube state through color recognition. The Kociemba algorithm computes near-optimal solutions, typically under 20 moves. A Python GUI provides real-time visualization of solving progress.

The system achieves consistent sub-second solve times while maintaining high accuracy in cube state detection across varying lighting conditions.
